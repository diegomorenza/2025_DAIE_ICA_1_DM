# Data Analytics for Immersive Environments – ICA Part A, B, D & E

This repository contains the Quarto Website developed for the individual
assignment in Data Analytics for Immersive Environments.

## Project Contents

This Quarto Website includes the following parts:

- **Part A – SQL Analysis**
  - SQL queries executed on an SQLite database
  - Core queries and SQL concept demonstrations
  - Results displayed using formatted and paginated tables

- **Part B – Linear Regression**
  - Linear regression model predicting production success rate
  - Based on production budget and crew size
  - Includes model output, plot, interpretation, and discussion

- **Part D – Technology Exploration**
  - Description of additional tools and technologies used

- **Part E – Conclusion and Reflection**
  - Summary of findings and reflection on learning outcomes

## How to Run the Project

1. Open the project in **RStudio** by double-clicking the `.Rproj` file.
2. Ensure required R packages are installed.
3. Click **Render** to build the Quarto Website.

## Main Files

- `index.qmd` – Home page
- `part_a_sql.qmd` – Part A: SQL
- `part_b_regression.qmd` – Part B: Linear Regression
- `technology_exploration.qmd` – Part D
- `conclusion.qmd` – Part E
